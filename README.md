# Offline Automation Systems Dashboard

## Project Overview

This project presents an interactive Power BI dashboard for exploring offline automation systems, company pricing, market segments, implementation methods, installation complexity, and unique selling propositions (USPs).

## Objectives

* Compare average prices across companies.
* Explore market segment distribution.
* Analyze system price ranges.
* Examine implementation methods and installation complexity.
* Summarize company offerings and USPs.

## Tools Used

* Microsoft Power BI Desktop
* Tableau Public
* CSV / tabular data

## Dashboard Features

* Company-level price comparison
* Market segment analysis
* System price range analysis
* Implementation complexity analysis
* USP comparison table

## Repository Contents

* `Offline_Automation_Dashboard.pbix` — Power BI report
* `README.md` — Project documentation
* `screenshots/` — Dashboard screenshots, when available
* `data/` — Dataset, if permitted for public distribution

## How to Use

1. Download the `.pbix` report from this repository.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, reconnect the data source to the included dataset or your local CSV file.

## Project Note

This repository documents a Tableau-to-Power-BI dashboard migration. Visualizations and report elements were recreated in Power BI.
